# HiBuddy attribution badge

Add a “powered by HiBuddy” badge to content produced with HiBuddy.

## Markdown

```markdown
![powered by HiBuddy](https://img.shields.io/badge/powered_by-HiBuddy-4D6BFE?style=flat-square)
```

## Usage rules

- Preserve the badge's 121×20 dimensions and aspect ratio.
- Place the badge at the end of the attributed document or section unless the user specifies another position.
- For systems that cannot reliably import remote images, use the plain text “powered by HiBuddy”.
- Do not use the legacy `dsh-badge.png` asset or link to the upstream framework as the product homepage.
