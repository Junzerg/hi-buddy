# HiBuddy 0.2.2-rc.1.20261119.1

[English](0.2.2-rc.1.20261119.1.md) | 中文

## 概述

[构建记录](0.2.2-rc.1.20261119.1.json)固定 `eb1bb0037d9ee9d4479111200b027a911c7d109b`（`dev/subcribe_test`），用于 Windows x64 无签名重新打包，以及后续 Mac arm64 签名并公证构建。它替换废弃的 20261117.3 Windows 构建；已发布的 20261117.2 仍是线上版本。按 [Desktop 打包交接](../desktop-packaging.zh.md)产出 Windows 安装包和平台归档。

## 登录按钮品牌深蓝

深色主题下登录按钮保持品牌深蓝。固定插件集与 20261117.3 相同，包含 Claude Kit 0.1.0-alpha.20。

## 平台验收与发布

在安装后的客户端验证全新安装及升级、启动与重启持久化、公司登录及授权模型、文本和图片对话、内网搜索与抓取、Office 预览及「标准」模式过程折叠。在 Claude 中续聊原生会话，并在同一项目并行运行两个会话。在回复过程中排队补充，确认补充送达后只显示一次，停止含未送达补充的会话，并把补充取回草稿。

发布采用 Windows 优先：Windows 安装包于 2026-11-19 通过本地验收，并于 2026-11-20 发布到内网 236.3，成为线上 Windows 版本；20261117.2 安装包仍可下载。Mac arm64 稍后构建，合并到同一发布目录形成双平台目录。
