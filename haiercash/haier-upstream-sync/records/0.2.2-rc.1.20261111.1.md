[The build record](0.2.2-rc.1.20261111.1.json) pins `d95f4df71c6f4177bacd8d3e1cfd0d320b976038` for Windows x64 unsigned and Mac arm64 signed and notarized installers. Use [the packaging handoff](../desktop-packaging.md) when the current pointer selects this record.

## Claude runtime

Claude kit 0.1.0-alpha.15 launches the SDK's bundled executable from its physical location under `app.asar.unpacked`. The Mac archive also unpacks the extensionless Claude executable. The Electron 44.7.0 fixture on Linux reproduced the old launch failure and verified that the final plugin tarball can run commands and resume a session through a local Anthropic Messages fixture.
