# HiBuddy 0.2.2-rc.1.20261113.1

[English](0.2.2-rc.1.20261113.1.md) | 中文

## 概述

[已确认记录](0.2.2-rc.1.20261113.1.json)固定版本 `0.2.2-rc.1.20261113.1`、源码 `31ea83293405f7c4e095f670e2b720ede4e0b1a0`、Windows x64 无签名和 Mac arm64 签名并公证。用户于 2026-11-13 确认上一版本两端构建均已结束。本版两端产物及安装验收均从待完成状态开始。遵循[打包交接](../desktop-packaging.zh.md)，完成安装包、平台归档、安装验收及联合发布。

## 源码与插件归档

源码包含海尔蓝主题、原有渐变 H、可交互海尔兄弟、统一页面背景、合并后的会话标题栏、侧栏调宽及 GUI 测试修复。同时包含槽位目录生成、导出契约文档，以及从远端合并的上一版已发布产物记录。kit 源码为 `9774aceeb5698def4948230b812850d53a0a87a2`；宿主固定 Claude `0.1.0-alpha.16`、术语表 `0.3.0-rc.2`、任务池 `0.2.2` 归档。记录包含三份归档的 SHA-256。Claude、术语表和文档库默认启用，任务池默认禁用。两台机器均通过冻结锁文件安装这些已提交归档。

## Package-set 重打

首次使用 `3528f1f707b6d38d14c014c6c1bba2244db27852` 打包时，`prepare-package-set` 因新旧 kit 归档包名重复而失败。按用户要求，本版现固定 `31ea83293405f7c4e095f670e2b720ede4e0b1a0`，供两个平台重新打包。修复删除了 Claude、术语表及任务池的旧归档，增加包名唯一和宿主归档钉点匹配的回归检查。两端从新钉点重新记录构建与安装验收证据。

## 两端验收

在两端安装后的客户端执行交接手册的海尔蓝视觉清单，覆盖深浅主题、新会话晃动及眼睛跟随、腿部渐进模糊、对话和轨迹右下角朦胧背景、设置页左下角背景、Claude 和术语表中间栏、侧栏渐变及调宽、单排会话标题、透明 Default 触发按钮。覆盖窄窗口和减少动态效果。验证全新安装及升级、IAM 登录与授权模型、文字及图片提示、内网搜索与抓取、内置 Claude、Office 预览及重启持久化。将失败及实际平台证据写入各自目标。

内网操作人员在登录及图片验收前，核对公司登录交换服务返回授权模型名称与图片能力。保留服务器凭据和现有路由；遵循既有[内网参考](../../../apps/desktop/packaging/INTRANET.md)和[交换服务部署流程](../../../apps/desktop/packaging/README.zh.md#company-login)。证据写入 `serverPrerequisites.companyLogin`。

## 验证证据与联合发布

JSON 记录统一保存本地检查结果、构建进度、安装包和归档名称及哈希、签名证据与安装验收。本地 GUI、浏览器及插件检查用于源码验证，各端另行记录本次安装结果。既有模型徽标浏览器回放失败与品牌场景分别记录。记录分别注明此前干净检出完整构建的源码提交，以及本次 package-set 修复的检查结果。

每位构建人员只更新自己的目标，保留另一平台结果。保留 EXE 或签名公证后的 DMG，以及对应 `lingxi-office-release-*.tar.gz`、feed、blockmap 和 Mac 签名 ZIP。两端及服务器前置项均验证后，取得发布授权，将两份归档合入同一个继承历史的发布目录并统一切换。线上验证成功前保持 `published: false`。任一平台开始后，固定源码和签名模式即被冻结。
