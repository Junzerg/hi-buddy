# HiBuddy 0.2.2-rc.1.20261110.2

[English](0.2.2-rc.1.20261110.2.md) | 中文

## 概述

[机器可读记录](0.2.2-rc.1.20261110.2.json) 为 Windows x64 未签名包和 Mac arm64 签名公证包固定源码提交 `2d93d2d927df3c2d86065bdced1a35001b740562`。当前入口切换到本记录后，按[打包交接指南](../desktop-packaging.zh.md)操作。平台构建与安装验收待完成。

## 内置功能

Claude kit 0.1.0-alpha.14 默认启用。安装包使用 Agent SDK 0.3.218 配套的 Claude Code 2.1.218 运行时，安装时保留平台可选依赖。Claude 从宿主读取模型和凭据。输入 `/model` 可为当前原生会话的下一轮选择宿主模型。本版也包含工作区文件与 Git 面板、可展开工具结果的原生会话记录，以及运行时命令菜单。

## 验证与验收

记录的 `checks` 字段列出源码和 Web 检查结果。宿主 Loader 使用本地 Anthropic Messages 模拟网关验证下一轮请求使用新模型 ID，且保留会话历史。Web 验证了从命令菜单打开选择器并选中模型。

两端分别安装并验证启动、公司登录、模型发现，以及通过公司网关进行 Claude 对话。用 `/model` 切换模型并继续同一会话，验证流式回复、工具审批、取消、重启后的记录保留和 Office 预览。Windows 检查随包 VC++ 运行库，Mac 检查签名和公证。记录安装包与发布归档的路径、大小、SHA-256 和安装验收结果。
