## Claude Kit

Claude Kit `0.1.0-alpha.20` lets users run independent sessions in the same project and queue text while Claude is working. A queued message appears in the conversation after Claude reads it. After stopping, the user can recover undelivered text into the draft. The build record pins the Kit source and archive checksum.
