# HiBuddy 0.2.2-rc.1.20261111.2

[English](0.2.2-rc.1.20261111.2.md) | 中文

## 概述

[打包记录](0.2.2-rc.1.20261111.2.json) 为 Windows x64 未签名包和 Mac arm64 签名公证包固定源码 `7f128c78f522c3107c460ea8635a7fab25ed59cb`。按[打包交接指南](../desktop-packaging.zh.md)生成安装包和发布归档。

## 桌面网页工具

桌面版将 `web_search` 和 `web_fetch` 请求发往 `http://172.28.236.3:18082/v1/tools`，使用企业登录或手动设置时保存的网关凭据。独立 Web profile 默认使用公网搜索提供方。已通过本地模拟网关验证构建后的桌面 profile 能带凭据搜索、抓取网页，并处理 HTTP 404。

## 安装验收

在两个目标平台的内网环境中安装或升级应用，登录后新建桌面会话，验证能搜索网页并抓取其中一条结果。同时检查模型发现和对话、内置 Claude 启动、Office 预览以及重启后的数据保留。记录两端实际安装包与发布归档的哈希，以及各平台的验收结果。
