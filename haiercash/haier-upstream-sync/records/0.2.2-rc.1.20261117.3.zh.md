# HiBuddy 0.2.2-rc.1.20261117.3

[English](0.2.2-rc.1.20261117.3.md) | 中文

## 概述

[构建记录](0.2.2-rc.1.20261117.3.json)固定 `5463d61cbf2dd338708d4657d06f1ef00d434815`，用于 Windows x64 无签名和 Mac arm64 签名并公证。按 [Desktop 打包交接](../desktop-packaging.zh.md)产出两端安装包和平台归档。

## Claude Kit

Claude Kit `0.1.0-alpha.20` 支持同项目独立会话并行，也支持在 Claude 工作期间排队补充文字。Claude 读到后，补充消息才进入对话。停止运行后，用户可将未送达的文字取回草稿。构建记录固定 Kit 源码和归档校验值。

## 平台验收与发布

在两端安装后的客户端验证全新安装及升级、公司登录及授权模型、文本和图片提示、内网搜索与抓取、Office 预览及重启持久化。在 Claude 中续聊原生会话，并在同一项目运行两个会话。在回复过程中提交补充并切换会话，确认补充送达后只显示一次。停止含未送达补充的会话，并把补充取回草稿。检查主会话「标准」模式的过程折叠。

每端构建人员记录本端安装包、归档和安装结果，Mac 记录签名与公证。两端均通过安装验收且获得发布授权后，合并两个归档并统一切换。
