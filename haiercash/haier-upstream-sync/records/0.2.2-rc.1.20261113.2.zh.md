## 会话标题栏与内置文档库

开始聊天后，关闭开发者工具时也可使用对话、轨迹及文档三个标签。文档标签打开文档库，并将会话视图恢复为对话供返回使用。标题栏更多菜单采用不透明的主题色表面，通过页面 body 浮层显示在会话内容上方。开发者工具的设置说明对应代码差异和 Agent 预设。

文档库归档为 `local-dsh-plugin-doclib-0.1.1.tgz`；旧归档缺少文档视图注册。package-set 测试将归档客户端与工作区客户端比较，并验证归档包名唯一性及两个平台的依赖闭包。记录固定归档 SHA-256 和源码，同时记录 Claude `0.1.0-alpha.16`、术语表 `0.3.0-rc.2` 和任务池 `0.2.2`。Claude、术语表及文档库默认启用，任务池默认禁用。两端通过冻结锁文件安装本源码中已提交的归档。

## 两端重新验收

在各端安装后的客户端关闭开发者工具，打开有消息的会话，核对三个标签及切换功能。打开文档后返回对话，在图片或文字消息上方打开更多菜单。两个导出选项都应完整显示且可点击，菜单表面不透明。检查 Escape、点击外部关闭、调整窗口大小及深浅主题。遵循交接手册其余海尔蓝检查项，覆盖背景、鼠标及眼睛互动、减少动态效果、单排标题和侧栏调宽。

验证全新安装及升级、公司登录与授权模型、文字及图片提示、内网搜索与抓取、内置 Claude、Office 预览及重启持久化。内网操作人员将公司登录交换服务的前置验证写入 `serverPrerequisites.companyLogin`。本地 Chromium 覆盖普通 Web 和 Windows 标题栏标记，实际 Windows 和 Mac 安装证据由各端构建人员提供。
