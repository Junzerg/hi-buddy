# Windows 灵犀连接器单测版

版本为 `0.2.2-rc.1.20261117.4-TRIAL`。Windows x64 负责人按[构建记录](0.2.2-rc.1.20261117.4-TRIAL.json)固定源码，生成无签名安装器和供手动交接的归档。使用独立 Windows 测试账户或虚拟机安装，更新地址指向本机回环，归档只供单测交接。正式双平台打包继续使用[原入口](../current-desktop-build.json)。

## Windows 构建

在 Windows 仓库中拉取专用分支，建立独立工作树。以下命令使用 Node >=24.9 和 pnpm 11.28.5。

```powershell
$ErrorActionPreference = 'Stop'
git fetch origin refs/heads/trial/windows-lingxi-20261117.4:refs/remotes/origin/trial/windows-lingxi-20261117.4
if ($LASTEXITCODE -ne 0) { throw 'Fetch failed' }
git worktree add --detach ..\hi-buddy-lingxi-trial origin/trial/windows-lingxi-20261117.4
if ($LASTEXITCODE -ne 0) { throw 'Trial worktree creation failed' }
Set-Location ..\hi-buddy-lingxi-trial
$record = Get-Content 'haiercash/haier-upstream-sync/records/0.2.2-rc.1.20261117.4-TRIAL.json' -Raw | ConvertFrom-Json
$version = $record.version
$target = $record.targets.'win-x64'
if (git status --porcelain) { throw 'The trial worktree must be clean' }
git switch --detach $record.sourceCommit
if ($LASTEXITCODE -ne 0) { throw 'Source checkout failed' }
if ((git rev-parse HEAD) -ne $record.sourceCommit) { throw 'Source does not match the record' }
foreach ($kit in $record.plugins.PSObject.Properties.Value) {
  if ((Get-FileHash $kit.archive -Algorithm SHA256).Hash -ne $kit.sha256) {
    throw "Plugin archive hash differs from the record at $($kit.archive)"
  }
}
if (Test-Path Env:DSH_PACKAGING_PRESET) { throw 'Open a PowerShell session without a packaging preset' }
$trialConfig = 'apps/desktop/.env.windows'
$configLines = @(
  "DSH_DESKTOP_APP_ID=$($target.appId)"
  "DSH_DESKTOP_INTRANET_UPDATE_URL=$($target.updateUrl)"
  'DSH_DESKTOP_WINDOWS_COMPRESSION_LEVEL=3'
)
if (Test-Path $trialConfig) {
  if ((Get-Content $trialConfig -Raw).TrimEnd() -ne ($configLines -join [Environment]::NewLine)) {
    throw 'Existing dotenv differs from the trial configuration'
  }
} else {
  $configLines | Set-Content -Path $trialConfig -Encoding ascii
}
pnpm install --frozen-lockfile
if ($LASTEXITCODE -ne 0) { throw 'Dependency installation failed' }
if (git status --porcelain) { throw 'Dependency installation changed tracked files' }
pnpm run package:desktop:win:x64:unsigned --build-version $version --check
if ($LASTEXITCODE -ne 0) { throw 'Packaging preflight failed' }
pnpm run package:desktop:win:x64:unsigned --build-version $version
if ($LASTEXITCODE -ne 0) { throw 'Installer build failed' }
$artifacts = 'apps/desktop/.desktop-build/targets/win-x64/unsigned-artifacts'
$installer = Join-Path $artifacts $target.expectedInstaller
$archive = Join-Path 'apps/desktop/.desktop-build' $target.expectedArchive
$engineBin = 'apps/desktop/.desktop-build/targets/win-x64/dsh/node_modules/@deepseek-ai/libreoffice-kit-win32-x64/bin'
foreach ($dll in @('msvcp140.dll', 'vcruntime140.dll')) {
  if (!(Test-Path (Join-Path $engineBin $dll))) { throw "Missing portable CRT DLL $dll" }
}
node apps/desktop/scripts/prepare-intranet-release.mjs win-x64 $artifacts $version $archive
if ($LASTEXITCODE -ne 0) { throw 'Trial archive generation failed' }
Get-Item $installer, $archive | Select-Object FullName, Length
Get-FileHash $installer, $archive -Algorithm SHA256
```

保留构建日志、安装器、归档和哈希。Windows 负责人只填写本记录的 `targets.win-x64` 实际构建与验收证据。单测人员从归档或安装文件手动安装。

## 236.3 测试服务

在 `172.28.236.3` 为 `lingxi-server` 准备独立工作目录、容器和数据目录。服务仅在宿主回环 `127.0.0.1:18891` 监听，由内网 TLS 入口反向代理。使用 Windows 信任且证书名称匹配的 HTTPS 地址。现有 `company-login` 使用自己的容器与路由。请 IAM 管理员给试用客户端登记完整的 `<HTTPS origin>/v1/auth/callback`。

在服务器侧导入与记录中 kit 提交匹配的 `lingxi-server-trial:20261117.4` 镜像。归档适用于 `uname -m` 返回 `x86_64` 的服务器。下例的状态目录由容器的 `node` 用户（UID 1000）持有。将 `trial.env` 权限设为 `0600`，由操作人员在服务器填写实际值。

```sh
uname -m
install -d -m 0700 /data/lingxi-office/lingxi-trial
install -d -m 0700 -o 1000 -g 1000 /data/lingxi-office/lingxi-trial/state
printf '%s\n' '75f0a9f27de4f809d23722f757bbe477d12fcb8e850d0cc2a73dfdde3b8749c0  lingxi-server-trial-20261117.4-linux-amd64.tar.gz' | sha256sum --check
docker load -i lingxi-server-trial-20261117.4-linux-amd64.tar.gz
docker image inspect lingxi-server-trial:20261117.4 --format '{{index .Config.Labels "org.opencontainers.image.revision"}}'
```

`trial.env` 中两个外部地址使用同一个已确认的 HTTPS origin。加密密钥使用该试用服务专用的随机值。飞书仅在试用应用已配置回调和凭据时进入验收。

## Windows 安装与验收

用同一个 PowerShell 窗口准备试用 profile。输入服务器部署后确认的 HTTPS origin。安装器完成时取消自动启动，再从该窗口启动应用，确保客户端进程读取试用的 `DSH_HOME`。

```powershell
$ErrorActionPreference = 'Stop'
$originUri = [Uri](Read-Host 'Lingxi trial HTTPS origin')
if (!$originUri.IsAbsoluteUri -or $originUri.Scheme -ne 'https' -or
    $originUri.AbsolutePath -ne '/' -or $originUri.UserInfo -or $originUri.Query -or $originUri.Fragment) {
  throw 'Enter an HTTPS origin without path, credentials, query or fragment'
}
$origin = $originUri.GetLeftPart([UriPartial]::Authority)
$service = Invoke-RestMethod -Uri "$origin/__version"
if ($service.name -ne 'lingxi-server' -or $service.mode -ne 'production') {
  throw 'The trial origin must serve lingxi-server in production mode'
}
$env:DSH_HOME = Join-Path $env:LOCALAPPDATA 'HiBuddy-Lingxi-20261117.4-TRIAL\harness'
$profile = Join-Path $env:DSH_HOME 'profiles\desktop'
$patch = Join-Path $profile 'cordis.patch.yml'
$trialPatch = @"
- insert:
    - id: hi-buddy-account-platform
      name: hi-buddy-account-platform
      config:
        endpoint: "$origin"
    - id: hi-buddy-connector-kit
      name: hi-buddy-connector-kit
      config:
        apiBaseUrl: "$origin"
- id: deepseek-account
  config:
    hiBuddyLogin: true
- id: agent-default-model
  config:
    provider: deepseek
    model: ''
"@
New-Item -ItemType Directory -Path $profile -Force | Out-Null
$patchText = $trialPatch.TrimEnd() + "`n"
if (Test-Path $patch) {
  if (([IO.File]::ReadAllText($patch)).TrimEnd() -ne $trialPatch.TrimEnd()) {
    throw 'Trial profile already exists with different settings'
  }
} else {
  [IO.File]::WriteAllText($patch, $patchText, [Text.UTF8Encoding]::new($false))
}
$env:NODE_USE_SYSTEM_CA = '1'
$exe = Read-Host 'Path to the installed trial HiBuddy.exe'
Start-Process -FilePath $exe
```

检查安装应用显示的版本、浏览器真实 IAM 登录、账号资料、重启恢复、连接器目录、演示记事本授权与读写、登出后工具移除和重新登录。发送对话验收 MCP 前，给试用 profile 选择有权使用的模型。使用相同 `DSH_HOME` 启动每次重启检查。另检查 Office 预览和试用更新地址。

需要撤回单测时，退出试用应用并停止 `lingxi-server-trial-20261117-4`，保留试用数据供诊断。合并前的两个源码提交和此前线上安装包版本见[回滚记录](2026-11-17-dev-xieyang-integration.json)。
