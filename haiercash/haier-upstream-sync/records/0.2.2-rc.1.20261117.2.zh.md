# HiBuddy 0.2.2-rc.1.20261117.2

[English](0.2.2-rc.1.20261117.2.md) | 中文

## 概述

[构建记录](0.2.2-rc.1.20261117.2.json)固定 `e095c9f9089f01289f10f7f4ddbcfcae271af18d`，用于 Windows x64 无签名和 Mac arm64 签名并公证。按 [Desktop 打包交接](../desktop-packaging.zh.md)产出两端安装包和平台归档。

## Claude Kit

Claude Kit `0.1.0-alpha.18` 新增带独立草稿的会话标签，将文件、改动与会话详情统一到右侧工作区，并支持在同一文件的多处改动间切换。用户可将带当前文件及行范围的反馈加入当前聊天草稿。构建记录固定 Kit 源码和归档校验值。

## 平台验收与发布

在两端安装后的客户端验证全新安装及升级、公司登录及授权模型、文本和图片提示、内网搜索与抓取、Office 预览及重启持久化。在 Claude 中续聊原生会话，切换各有草稿的标签，预览工作区文件，并对某处改动添加反馈。确认当前草稿包含反馈及其文件和行范围。检查宿主搜索和主会话「标准」模式的过程折叠。

每端构建人员记录本端安装包、归档和安装结果，Mac 记录签名与公证。两端均通过安装验收且获得发布授权后，合并两个归档并统一切换。
