## Preview evidence

The earlier `git merge-tree --write-tree --name-only -z` preview reported 315 conflicting files: 241 content conflicts and 74 modify/delete conflicts. Among those files, 102 were package manifests and 60 were locale JSON files; these categories overlap the conflict types. These counts do not describe the newer head.

Sampled conflicts included adjacent package description/version edits, layout drawer and resizing changes, desktop menu changes, account-menu presentation and shared application-access text. Core behavior has not been audited merely because its files merged automatically.
