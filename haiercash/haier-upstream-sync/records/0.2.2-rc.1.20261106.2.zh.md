# HiBuddy 0.2.2-rc.1.20261106.2

[English](0.2.2-rc.1.20261106.2.md) | 中文

## 概述

用户确认本版本面向 Windows x64 和 Mac arm64。[机器可读记录](0.2.2-rc.1.20261106.2.json)维护准确源码提交、插件默认状态和验收状态。执行命令见[打包交接](../desktop-packaging.zh.md)。前一个 `.1` 编号已使用，不得复用。

## 证据与限制

源码构建和类型检查通过。依赖包集合测试通过 22 项，覆盖两个目标架构。全新 profile 的 Web 测试验证内置术语表默认加载、两个默认词条启用、会话池关闭。已有同名用户定义保持不变；开发机用户数据不会打入安装包。

此前模型选择相关浏览器回归仍有未解决的失败。本版本尚未验证安装器、真实签名／公证、目标系统安装及升级。Linux 上的准备工作不能替代这些检查。对应平台操作人员必须记录实际产物和验收结果后，才能报告交付；本记录不授权发布。

用户确认两端均未开始打包后，源码提交已更新为包含隐藏“内置插件”设置入口的修复。该修复的全新 profile Web 测试及构建检查通过。

双平台曾基于 6ba59f46e4 发布上线，随后因 Office 文档预览在系统 MSVCP140.dll 过旧的机器上以 0xC0000005 崩溃而回滚；仅一台客户端安装过。版本身份作废，绝不同号重发：可移植 VC++ 运行库修复改以 0.2.2-rc.1.20261107.1 发布，因为同号重发无法让已安装本版本的客户端自动更新。

此前 pin 构建的 Windows 安装包在 LibreOffice 引擎旁缺少可移植 VC++ 运行库，系统 MSVCP140.dll 过旧的机器上 Office 预览失败。该 fail-closed 的可移植 CRT 修复包含在 0.2.2-rc.1.20261107.1 的源码提交中。
