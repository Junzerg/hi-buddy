# HiBuddy 0.2.2-rc.1.20261107.1

[English](0.2.2-rc.1.20261107.1.md) | 中文

## 概述

用户在 `0.2.2-rc.1.20261106.2` Mac 打包因产物搬迁失败后确认使用新版本。目标平台仍为 Windows x64 与 Mac arm64。[机器可读记录](0.2.2-rc.1.20261107.1.json)维护准确源码提交、插件默认状态和验收状态。执行命令见[打包交接](../desktop-packaging.zh.md)。不得复用 `0.2.2-rc.1.20261106.2`。

## 证据与限制

打包源码提交已使 Mac DMG／ZIP 搬迁与 electron-builder 已输出的 HiBuddy 产物名一致。修复后，`package-macos`、`macos-signature` 与 `installer-packaging` 聚焦测试通过。被替代准备中的源码构建、依赖包集合与全新 profile Web 证据仍然适用；模型选择相关浏览器回归仍未解决。本版本尚未验证安装器、真实签名／公证、目标系统安装及升级。对应平台操作人员必须记录实际产物和验收结果后，才能报告交付；本记录不授权发布。
