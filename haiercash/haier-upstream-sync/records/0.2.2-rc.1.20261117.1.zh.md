# HiBuddy 0.2.2-rc.1.20261117.1

[English](0.2.2-rc.1.20261117.1.md) | 中文

## 概述

[构建记录](0.2.2-rc.1.20261117.1.json)固定 `3df195ddc9ad9034fb622c2f275ceb0d6bf786f2`，用于 Windows x64 无签名和 Mac arm64 签名并公证。用户已确认联合构建，并确认上一版本两端均已停建。按 [Desktop 打包交接](../desktop-packaging.zh.md)产出两端安装包和平台归档。

## 会话与 Claude Kit

会话采用上游的过程分组、命令与文件行及完成控件。「标准」工作步骤展示允许用户在运行中展开和收起过程。完成后可查看最终回答，回答保留 HiBuddy 品牌头。

内置 Claude Kit `0.1.0-alpha.17` 包含会话展示、SDK 控制及通过 Host 提供的网页搜索。构建记录固定 Kit 源码和归档 SHA-256。两端使用冻结锁文件安装同一份归档。

## 平台验收与发布

在两端安装后的客户端验证全新安装和升级、启动、公司登录、模型发现、文本和图片提示、内网搜索与抓取、Office 预览及重启持久化。检查深浅主题。在「标准」模式的会话中验证运行时展开和收起过程，打开单行命令与文件记录，检查最终回答和品牌头。在 Claude 中续聊原生会话，验证 SDK 控制并使用已配置的 Host 供应商执行网页搜索。

各构建人员记录本端安装包、平台归档和安装验收证据。Mac 记录签名和公证证据。在内网验证公司登录交换服务。两端均通过安装验收且获得发布授权后，合并两个归档并一起发布。
