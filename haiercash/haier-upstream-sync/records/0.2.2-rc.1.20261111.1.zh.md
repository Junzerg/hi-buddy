## 概述

[打包记录](0.2.2-rc.1.20261111.1.json) 为 Windows x64 未签名包和 Mac arm64 签名公证包固定源码 `d95f4df71c6f4177bacd8d3e1cfd0d320b976038`。当前入口指向本记录后，按[打包交接指南](../desktop-packaging.zh.md)操作。

## Claude 运行时

Claude kit 0.1.0-alpha.15 从 `app.asar.unpacked` 中的实际磁盘路径启动 SDK 自带的可执行文件。Mac 归档也会解包没有扩展名的 Claude 可执行文件。Linux 上的 Electron 44.7.0 夹具复现了旧版启动失败，并用本地 Anthropic Messages 模拟网关验证最终插件包能执行命令和续聊。

## 安装验收

在没有单独安装 Claude CLI 的机器上从上一版升级。打开 Claude，新建任务并确认首条消息完成。通过公司网关验证原生会话续聊和 `/model` 切换模型。检查应用启动、公司登录、Office 预览及重启后的数据保留。记录两端的安装包与发布归档哈希和实际验收结果。
