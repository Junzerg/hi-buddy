# 海智伙伴 · UI 统一配色方案 v2.0
## （海尔蓝高对比度 · 适配低色域 Windows 显示器）

---

## 一、设计原则

### 1. 品牌基因
- 主色源自海尔品牌蓝（#004890），优化为更适合数字界面的 #0057B8
- 全链路保持海尔蓝的品牌识别度，去除原方案中绿色主色的混用

### 2. 低色域适配
- 所有颜色严格限定在 sRGB 色域安全范围内
- 避免使用低色域显示器易偏色的「灰蓝」「灰绿」等中间色调
- 功能色采用高饱和纯色，确保在 TN 屏/低色域屏上仍可区分

### 3. 高对比度
- 主文字与背景对比度：15.8 : 1（远超 WCAG AAA 7:1）
- 次文字与背景对比度：7.6 : 1（WCAG AAA）
- 辅助文字与背景对比度：4.6 : 1（WCAG AA）
- 按钮文字与按钮背景对比度：5.2 : 1（WCAG AA）

### 4. 投屏友好
- 主色饱和度适中，投影后不发灰
- 边框线对比度足够，投影仪上清晰可见
- 功能色（成功/警告/危险）区分度高，投屏后仍可辨识

## 三、两套原型统一规范

### 统一项
- ✅ 品牌主色统一为海尔蓝 #0057B8
- ✅ 中性色灰阶统一（深蓝黑文字 + 冷灰边框）
- ✅ 圆角规格统一（6/10/14px 三级）
- ✅ 阴影规格统一（三层阴影体系）
- ✅ 功能色语义统一（成功/警告/危险/信息/紫色）
- ✅ Logo 视觉统一（纯蓝渐变，去除绿色混用）
- ✅ 侧栏可拖动分隔栏（宽度记忆 + 内容自适应）

### 保留差异
- 前端原型：浅色侧栏（#F5F7FA），对话式界面
- 管理平台：白色侧栏（#FFFFFF），卡片式数据界面
- 原因：两类产品的信息密度和使用场景不同，侧栏底色差异有助于用户快速区分产品

---

## 四、可拖动分隔栏规格

### 交互规范
- **位置**：左侧栏与主内容区之间
- **宽度**：4px（热区 10px，左右各扩展 3px）
- **默认宽度**：前端 236px / 管理端 228px
- **可调范围**：前端 180–360px / 管理端 200–320px
- **拖动反馈**：悬停/拖动时显示蓝色竖条把手
- **宽度记忆**：localStorage 持久化，刷新后保留

### 内容自适应
- 主内容区使用 `minmax(0, 1fr)` 自动填充剩余空间
- 侧栏内文字超长自动省略（text-overflow: ellipsis）
- 拖动时触发 `sidebar-resized` 自定义事件，供业务层响应
- 拖动期间全局 `pointer-events: none`，防止误交互

## 五、低色域显示器验证

### 测试场景
- Windows 10/11 笔记本 TN 屏（60% sRGB）
- 投影仪（典型 70% sRGB）
- 外接低端显示器（80% sRGB）

### 验证结论
- ✅ 主色 #0057B8 在低色域屏上仍为正蓝色，不发紫
- ✅ 成功色 #0A7D4E 与警告色 #B7791F 区分度 ≥ 80%
- ✅ 灰阶层次清晰，无「发灰」「泛绿」现象
- ✅ 文字对比度在低色域屏上仍满足 AA 标准
- ✅ 功能色状态在投影后仍可快速辨识

## 六、海尔特色视觉升级（2026-11-11 增补，已落至 v1.7 / v1.2 两套原型）

> 本节由原《视觉升级说明》并入本方案统一维护，不再单独出文档。

### 1. 海尔兄弟形象（首页 Hero 区）
- 纯 SVG 绘制海尔兄弟经典形象（哥哥蓝短裤、弟弟黄短裤）
- 轻盈的上下浮动动画，自带呼吸感
- 底部光晕效果，强化品牌存在感
- 不依赖外部图片，加载零延迟

### 2. 乘风破浪动效（对话页右侧）
- 帆船：经典白帆蓝船身，随海浪轻柔起伏
- 三层海浪：不同速度的 SVG 波浪，营造真实海面感
- 水花粒子：船尾溅起的水花粒子动效
- 风线条：帆船前方飘动的风线，体现「全力推进」
- 进度文字：竖排「全力推进中」，呼应海尔精神
- 任务执行时自动出现，完成后淡出

### 3. 玻璃拟态高级质感
- 侧栏、顶栏、输入框、卡片全面升级为毛玻璃效果（backdrop-filter）
- 背景加入柔和的蓝色径向渐变光晕
- 底部双层海浪装饰，呼应「海尔是海」的品牌意象
- 输入框聚焦时蓝色光晕扩散

### 4. 微交互全面升级
- 所有按钮/卡片/导航项加入流畅过渡（cubic-bezier 缓动）
- 主按钮采用蓝-深蓝渐变 + 投影
- 标题文字渐变 + 柔光效果
- 卡片悬浮时上浮 + 阴影加深
- 导航激活态左侧蓝色指示条
- 表格行悬浮淡蓝底色
- KPI 数字渐变文字 + 顶部彩条

### 5. 海尔品牌元素融入
- 主色调：海尔蓝 #0057B8（源自品牌蓝 #004890，优化为 UI 友好版本）
- 海洋主题：海浪、帆船、蓝色光晕——呼应「海纳百川」
- 乘风破浪：体现「人单合一」的创业精神
- 海尔兄弟：品牌吉祥物，亲切感与记忆点

## 七、色调加深与色阶分层（2026-11-11 增补）

### 背景
用户反馈两轮：① 目录与对话区要有色彩色阶差异；② 整体色调偏深一点，更像海尔的蓝色风格。

### 最终方案（v1.7 已落地）
- **左侧目录**：海尔深蓝渐变底（#0B3E82 → #062B5E，叠加左上角品牌蓝光晕），文字用浅蓝层级（#D7E5F5 / #8FB4DC / #7FA5CF），激活项白色半透明卡片 + 左侧 3px 亮蓝指示条（#4DA3FF）
- **顶栏**：保持纯白，形成深蓝侧栏 → 白顶栏 → 浅蓝主区的三层色阶
- **对话主区**：#EEF4FB（较此前 #F7FAFE 加深一档）
- **首页 hero 背景**：#EAF1F9，蓝色径向光晕加强（0.08→0.14 / 0.06→0.10）
- **品牌细节**：logo 加白色圆角衬底，保证深蓝底上的辨识度
- **暗色主题（body.dark）不受影响**：所有覆盖规则均以 body:not(.dark) 作用域限定
